# مجموعه پرامپت‌های Google Stitch
## طراحی UI نرم‌افزار حرفه‌ای فروشگاه، انبار و مالی

## دستورالعمل مشترک برای همه صفحات
```text
یک نرم‌افزار SaaS حرفه‌ای فارسی و راست‌به‌چپ برای مدیریت فروشگاه، انبار، خرید، فروش و امور مالی طراحی کن. رابط کاربری مدرن، خلوت، سریع و مناسب استفاده روزانه باشد. از فونت فارسی خوانا مانند Vazirmatn، رنگ اصلی سرمه‌ای عمیق، رنگ تأکیدی آبی، سبز برای موفقیت، نارنجی برای هشدار و قرمز برای خطا استفاده کن. طراحی دسکتاپ‌محور اما کاملاً واکنش‌گرا باشد. ساختار شامل سایدبار راست با منوی دسته‌بندی‌شده، هدر با جستجوی سراسری، اعلان‌ها، انتخاب شعبه و پروفایل کاربر باشد. از کارت‌های آماری، جدول‌های حرفه‌ای، فیلتر، مرتب‌سازی، pagination، breadcrumb، modal، drawer، tooltip و empty state استفاده کن. اعداد، تاریخ و واحد پول برای ایران و تومان باشند. متن‌ها فارسی، واضح و کاربرپسند باشند. دسترسی‌پذیری، کنتراست مناسب، حالت loading، خطا و موفقیت را رعایت کن. از شلوغی بصری و نمودارهای غیرضروری پرهیز کن.
```

## پرامپت ۱ — ورود و احراز هویت
```text
بر اساس دستورالعمل مشترک، صفحه ورود نرم‌افزار مدیریت فروشگاه را طراحی کن: لوگو، نام سامانه، شماره موبایل یا ایمیل، رمز عبور، نمایش/مخفی‌سازی رمز، مرا به خاطر بسپار، ورود، فراموشی رمز و ورود دو مرحله‌ای. صفحه‌ای حرفه‌ای با تصویر انتزاعی بسیار ظریف در سمت چپ و فرم در سمت راست ایجاد کن. حالت خطا، loading و پیام اعتبارسنجی را هم نشان بده.
```

## پرامپت ۲ — داشبورد اصلی
```text
یک داشبورد مدیریتی فارسی برای فروشگاه طراحی کن. بالای صفحه کارت‌های فروش امروز، سود ناخالص، موجودی کالا، بدهی مشتریان و مطالبات تأمین‌کنندگان را نمایش بده. نمودار فروش ۳۰ روز اخیر، فروش بر اساس دسته‌بندی، محصولات پرفروش، هشدار موجودی کم، فاکتورهای سررسیدشده و فعالیت‌های اخیر را اضافه کن. قابلیت انتخاب بازه زمانی و شعبه داشته باشد.
```

## پرامپت ۳ — فروش سریع POS
```text
صفحه فروش سریع صندوق طراحی کن. سمت راست جستجو و اسکن بارکد، دسته‌بندی کالا و لیست محصولات؛ سمت چپ سبد خرید، تعداد، تخفیف، مالیات، مبلغ نهایی و انتخاب مشتری. دکمه‌های پرداخت نقدی، کارت، ترکیبی و ثبت پیش‌فاکتور داشته باشد. صفحه برای استفاده با کیبورد و نمایشگر لمسی بهینه باشد.
```

## پرامپت ۴ — فهرست فاکتورهای فروش
```text
صفحه فهرست فاکتورهای فروش طراحی کن: جدول شماره فاکتور، مشتری، تاریخ، مبلغ، وضعیت پرداخت، کاربر و عملیات. فیلتر بر اساس بازه تاریخ، مشتری، وضعیت و روش پرداخت، جستجو، خروجی Excel/PDF، چاپ و ایجاد فاکتور جدید را اضافه کن. وضعیت‌ها با badge رنگی و منوی عملیات سه‌نقطه نمایش داده شوند.
```

## پرامپت ۵ — ایجاد فاکتور فروش
```text
فرم حرفه‌ای ایجاد فاکتور فروش طراحی کن. انتخاب مشتری، تاریخ، شماره فاکتور، جدول افزودن کالا با جستجوی سریع، بارکد، تعداد، قیمت، تخفیف، مالیات و انبار را داشته باشد. پایین فرم جمع جزء، تخفیف، مالیات، هزینه حمل و مبلغ نهایی را نشان بده. دکمه ذخیره پیش‌نویس، ثبت نهایی، چاپ و ارسال برای مشتری اضافه کن.
```

## پرامپت ۶ — جزئیات و چاپ فاکتور
```text
صفحه جزئیات فاکتور فروش طراحی کن: سربرگ فروشگاه، اطلاعات مشتری، جدول اقلام، جمع مبالغ، وضعیت پرداخت، تاریخچه تغییرات و یادداشت. دکمه‌های چاپ، دانلود PDF، ارسال پیامک/ایمیل، مرجوعی و ثبت پرداخت را در هدر قرار بده. نسخه چاپی رسمی و مناسب کاغذ A4 نیز طراحی کن.
```

## پرامپت ۷ — مشتریان
```text
صفحه مدیریت مشتریان طراحی کن. جدول نام، تلفن، تعداد خرید، مجموع خرید، بدهی و آخرین خرید داشته باشد. فیلتر مشتریان بدهکار و وفادار، افزودن مشتری، ورود گروهی، خروجی گرفتن و جستجوی سریع را اضافه کن.
```

## پرامپت ۸ — پروفایل مشتری
```text
صفحه پروفایل مشتری طراحی کن با خلاصه اعتبار، سقف خرید نسیه، مانده بدهی، امتیاز وفاداری و اطلاعات تماس. تب‌های فاکتورها، پرداخت‌ها، مرجوعی‌ها، یادداشت‌ها و تاریخچه تعاملات داشته باشد. دکمه ثبت پرداخت و ایجاد فاکتور را برجسته کن.
```

## پرامپت ۹ — فهرست کالاها
```text
صفحه مدیریت کالاها طراحی کن. جدول تصویر، نام، SKU، بارکد، دسته‌بندی، موجودی، حداقل موجودی، قیمت خرید، قیمت فروش و وضعیت داشته باشد. فیلتر انبار، دسته‌بندی، موجود/ناموجود و موجودی کم، افزودن کالا، ورود گروهی و خروجی Excel را اضافه کن.
```

## پرامپت ۱۰ — ایجاد و ویرایش کالا
```text
فرم چندبخشی ایجاد کالا طراحی کن: اطلاعات پایه، بارکد و SKU، واحد اندازه‌گیری، دسته‌بندی، برند، قیمت خرید و فروش، مالیات، حداقل موجودی، انبارها، تصویر و توضیحات. فرم دارای تب یا stepper، پیش‌نمایش کالا و اعتبارسنجی واضح باشد.
```

## پرامپت ۱۱ — موجودی انبار
```text
صفحه کنترل موجودی انبار طراحی کن. کارت‌های ارزش کل موجودی، کالاهای کم‌موجودی، کالاهای بدون موجودی و کالاهای راکد را نمایش بده. جدول موجودی بر اساس انبار، کالا، ورودی، خروجی، رزرو و قابل فروش باشد. عملیات انتقال، تعدیل موجودی و مشاهده گردش کالا را اضافه کن.
```

## پرامپت ۱۲ — جزئیات گردش کالا
```text
صفحه گردش یک کالا طراحی کن. اطلاعات کالا و موجودی فعلی در بالا و جدول زمانی تمام ورودها، خروجی‌ها، انتقال‌ها، تعدیلات و مرجوعی‌ها در پایین باشد. فیلتر زمانی، انبار و نوع تراکنش و امکان مشاهده سند مرجع را اضافه کن.
```

## پرامپت ۱۳ — انبارها و شعب
```text
صفحه مدیریت انبارها و شعب طراحی کن. هر انبار به شکل کارت با نام، آدرس، مدیر، تعداد کالا، ارزش موجودی و وضعیت نمایش داده شود. عملیات افزودن، ویرایش، غیرفعال‌سازی، مشاهده موجودی و انتقال بین انبارها را قرار بده.
```

## پرامپت ۱۴ — انتقال بین انبارها
```text
فرم انتقال کالا بین دو انبار طراحی کن: انبار مبدأ، مقصد، تاریخ، شماره سند، کالاها، تعداد، توضیحات و وضعیت انتقال. مسیر انتقال را به صورت stepper «درخواست، ارسال، دریافت» نمایش بده و دکمه ثبت و تأیید دریافت داشته باشد.
```

## پرامپت ۱۵ — خرید و تأمین‌کنندگان
```text
صفحه خرید طراحی کن با کارت‌های خرید ماه جاری، بدهی تأمین‌کنندگان، سفارش‌های باز و خریدهای در انتظار دریافت. جدول سفارش خرید، تأمین‌کننده، مبلغ، وضعیت و تاریخ تحویل داشته باشد. ایجاد سفارش خرید، ثبت رسید کالا و خروجی را اضافه کن.
```

## پرامپت ۱۶ — ایجاد سفارش خرید
```text
فرم ایجاد سفارش خرید طراحی کن: انتخاب تأمین‌کننده، انبار مقصد، تاریخ، مهلت پرداخت، اقلام کالا، تعداد، قیمت خرید، تخفیف، مالیات، هزینه حمل و جمع کل. امکان ذخیره پیش‌نویس، ارسال برای تأیید و ثبت رسید جزئی فراهم باشد.
```

## پرامپت ۱۷ — تأمین‌کنندگان
```text
صفحه فهرست تأمین‌کنندگان طراحی کن با نام شرکت، شخص تماس، تلفن، تعداد سفارش، خرید کل، بدهی و وضعیت. صفحه پروفایل تأمین‌کننده شامل سفارش‌ها، پرداخت‌ها، فاکتورها و مانده حساب باشد.
```

## پرامپت ۱۸ — صندوق و پرداخت‌ها
```text
صفحه مدیریت صندوق و تراکنش‌های پرداخت طراحی کن. موجودی صندوق‌ها، دریافت امروز، پرداخت امروز و مانده حساب را نمایش بده. جدول تراکنش‌ها با نوع، طرف حساب، روش پرداخت، مبلغ، تاریخ و سند مرجع داشته باشد. ثبت دریافت، پرداخت و انتقال وجه را اضافه کن.
```

## پرامپت ۱۹ — حساب‌های مالی
```text
صفحه مالی طراحی کن با خلاصه درآمد، هزینه، سود، مطالبات، بدهی‌ها و جریان نقدی. بخش‌های دریافتنی‌ها، پرداختنی‌ها، هزینه‌ها، درآمدها و حساب‌های بانکی را با کارت و جدول قابل فیلتر نمایش بده.
```

## پرامپت ۲۰ — گزارش فروش ماهیانه
```text
صفحه گزارش فروش ماهیانه طراحی کن. انتخاب ماه، شعبه و کانال فروش داشته باشد. نمودار فروش روزانه، مقایسه با ماه قبل، سود ناخالص، میانگین مبلغ فاکتور، تعداد فاکتورها، فروش دسته‌بندی‌ها و کالاهای پرفروش را نمایش بده. خروجی PDF و Excel اضافه کن.
```

## پرامپت ۲۱ — گزارش سود و زیان
```text
گزارش سود و زیان حرفه‌ای طراحی کن با انتخاب بازه زمانی. درآمد فروش، بهای تمام‌شده، تخفیف، مرجوعی، هزینه‌ها و سود خالص را به صورت کارت و جدول سلسله‌مراتبی نمایش بده. امکان مقایسه با دوره قبل و چاپ رسمی وجود داشته باشد.
```

## پرامپت ۲۲ — گزارش موجودی
```text
صفحه گزارش موجودی طراحی کن با ارزش موجودی به تفکیک انبار و دسته‌بندی، کالاهای کم‌گردش، راکد، رو به اتمام و مازاد. جدول قابل مرتب‌سازی و خروجی Excel/PDF داشته باشد.
```

## پرامپت ۲۳ — مرجوعی فروش
```text
صفحه مرجوعی فروش طراحی کن. جستجوی فاکتور، انتخاب اقلام و مقدار مرجوعی، علت، وضعیت کالا، روش بازپرداخت و اثر بر موجودی را نشان بده. مراحل درخواست، تأیید و تکمیل مرجوعی با stepper نمایش داده شود.
```

## پرامپت ۲۴ — تخفیف و قیمت‌گذاری
```text
صفحه مدیریت قیمت‌ها و تخفیف‌ها طراحی کن. لیست قیمت‌ها، تخفیف درصدی یا مبلغی، بازه اعتبار، کالا یا دسته مشمول و وضعیت فعال را نمایش بده. فرم ساخت کمپین تخفیف با پیش‌نمایش اثر روی فاکتور طراحی کن.
```

## پرامپت ۲۵ — کاربران و نقش‌ها
```text
صفحه کاربران و نقش‌های دسترسی طراحی کن. جدول کاربران، نقش، شعبه، آخرین ورود و وضعیت را نمایش بده. فرم نقش جدید با مجوزهای ماژول‌محور شامل مشاهده، ایجاد، ویرایش، حذف، تأیید و خروجی طراحی کن.
```

## پرامپت ۲۶ — لاگ فعالیت‌ها
```text
صفحه audit log طراحی کن که تمام فعالیت‌های کاربران را با کاربر، عملیات، ماژول، تاریخ، IP و نتیجه نمایش دهد. فیلتر پیشرفته، مشاهده جزئیات قبل و بعد از تغییر و خروجی گزارش را اضافه کن.
```

## پرامپت ۲۷ — تنظیمات فروشگاه
```text
صفحه تنظیمات با تب‌های اطلاعات فروشگاه، لوگو، واحد پول، مالیات، شماره‌گذاری اسناد، قالب فاکتور، اعلان‌ها، پیامک، ایمیل و تنظیمات پشتیبان‌گیری طراحی کن. تغییرات حساس نیازمند تأیید مجدد باشند.
```

## پرامپت ۲۸ — اعلان‌ها و مرکز پیام
```text
مرکز اعلان‌ها طراحی کن با دسته‌بندی هشدار موجودی کم، سررسید بدهی، سفارش خرید، خطای سیستم و فعالیت کاربران. هر اعلان دارای اولویت، زمان، وضعیت خوانده‌شده و لینک به صفحه مرتبط باشد.
```

## پرامپت ۲۹ — جستجوی سراسری
```text
یک overlay جستجوی سراسری طراحی کن که با کلید میانبر باز شود و در کالاها، مشتریان، فاکتورها، سفارش‌های خرید و گزارش‌ها جستجو کند. نتایج دسته‌بندی‌شده، پیشنهادهای اخیر، میانبرهای صفحه و حالت بدون نتیجه داشته باشد.
```

## پرامپت ۳۰ — حالت‌های سیستمی
```text
برای تمام صفحات این نرم‌افزار نمونه‌های loading با skeleton، empty state، خطای شبکه، خطای دسترسی، فرم بدون داده، پیام موفقیت، پیام تأیید حذف و صفحه 404 طراحی کن. متن‌ها فارسی و راهنمای اقدام بعدی واضح باشند.
```

## پرامپت ۳۱ — طراحی موبایل و تبلت
```text
نسخه واکنش‌گرای همین نرم‌افزار را برای تبلت و موبایل طراحی کن. سایدبار به bottom navigation یا drawer تبدیل شود، جدول‌ها به کارت‌های قابل اسکرول تبدیل شوند، فرم‌های طولانی stepper داشته باشند و عملیات مهم مانند فروش سریع، ثبت دریافت و مشاهده موجودی با یک دست قابل استفاده باشند.
```

## پیشنهاد ترتیب ساخت در Google Stitch
1. دستورالعمل مشترک را در ابتدای پروژه وارد کن.
2. ابتدا پرامپت‌های داشبورد، فروش سریع و فهرست کالاها را اجرا کن تا Design System شکل بگیرد.
3. سپس صفحات فاکتور، انبار، خرید و مالی را با عبارت «همان Design System قبلی را حفظ کن» بساز.
4. در پایان صفحات گزارش، تنظیمات، دسترسی‌ها و حالت‌های سیستمی را اضافه کن.
5. در همه خروجی‌ها تأکید کن: «از داده نمونه واقعی‌نما استفاده کن، اما هیچ API یا بک‌اندی پیاده‌سازی نکن؛ فقط UI و تعاملات نمایشی طراحی کن.»
